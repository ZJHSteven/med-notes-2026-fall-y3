## 二、尿液检验——标本采集与保存

### 1. 尿标本的正确采集

尿液标本（Urine Specimen）的质量直接影响结果的可靠性。

**（1）晨尿的选择**

- **第一次晨尿（First Morning Urine）**：经过夜间浓缩，尿液较浓且偏酸，有利于提高尿液有形成分的阳性检出率。
- **第二次晨尿（Second Morning Urine）**：可减少第一次晨尿在膀胱内长期储存所致的细胞、管型形态改变。

【实验室应用】老师介绍，目前进行尿液相差显微镜检查（Phase-contrast Microscopy）时，主要推荐使用第二次晨尿。

**（2）避免标本污染**

- 女性：避免混入月经血（Menstrual Blood）和阴道分泌物。
- 男性：避免混入前列腺液（Prostatic Fluid）和精液（Semen）。
- 一般采用清洁中段尿（Clean-catch Midstream Urine）。
- 无法自行排尿、确有检验需要者，可由医护人员通过导尿（Catheterization）取得标本。

**（3）及时检测与保存**

- 课堂要求尿标本采集后尽量在 **2小时内完成检查**。
- 不能及时检查时，可在约4℃冷藏，或根据检测项目使用合适的防腐剂（Preservatives）。
- 最好使用新鲜、未加防腐剂的尿标本。

### 2. 尿液环境对有形成分的影响

尿液渗透压（Osmolality）和酸碱度（pH）会改变红细胞、白细胞和管型的形态。

| 尿液环境 | 红细胞（RBC） | 白细胞（WBC） | 管型（Casts） |
|---|---|---|---|
| 高渗尿 | 皱缩，可呈星芒状、棘状 | 皱缩 | 影响相对较小 |
| 低渗尿 | 吸水膨胀、变形，甚至溶血 | 肿胀 | 肿胀、崩解 |
| 酸性尿 | 可皱缩，但保存时间相对较长 | 可皱缩，保存相对较好 | 较稳定 |
| 碱性尿 | 肿胀、溶解 | 肿胀、形成泡状结构 | 容易分解 |

【易错】尿液中红细胞形态异常并不必然意味着肾小球疾病，**渗透压、pH及标本保存时间**均可能造成继发性形态变化。

### 3. 常见尿液防腐剂

| 防腐剂 | 主要用途 | 注意事项 |
|---|---|---|
| 甲醛（Formaldehyde） | 固定细胞、管型等有形成分 | 不宜用于葡萄糖检查，可干扰部分试带反应 |
| 甲苯（Toluene） | 尿糖、尿蛋白定性或定量 | 具体适用范围取决于方法 |
| 麝香草酚（Thymol） | 显微镜检查，尤其某些结核分枝杆菌及化学成分检查 | 可能干扰部分化学反应 |
| 浓盐酸（Concentrated Hydrochloric Acid） | 17-羟皮质类固醇、17-酮类固醇、儿茶酚胺、草酸盐、钙、磷等项目的特定收集流程 | 不用于常规尿筛查 |
| 硼酸（Boric Acid） | 某些蛋白质、尿酸、5-羟吲哚乙酸、羟脯氨酸、皮质醇、雌激素等检测的保存方案 | 可能影响尿pH检测 |
| 碳酸钠（Sodium Carbonate） | 卟啉、尿胆原等特定检查 | 不用于常规尿筛查 |

老师还提到一种有形成分保存方法：每升尿液加入约5 mL的40%甲醛溶液。

【术语纠正】转写中的“40%甲醇”结合固定细胞及管型的用途，应为**40%甲醛（福尔马林，Formalin）**；“石质香、皮脂类固醇”应为17-羟皮质类固醇等相关项目；“铜酸”应为硼酸；“补磷”应为卟啉。

【检验注意】这些是课堂介绍的传统防腐方法，不代表所有现代检验平台均可通用。实际操作应按检测项目及实验室SOP选择保存剂，不能对所有尿标本统一添加。

## 三、尿液检验的三大部分

尿液检查包括：

| 类别 | 主要检查项目 |
|---|---|
| 外观和理学检查（Physical Examination） | 尿量、气味、颜色、透明度、尿比重 |
| 化学分析（Chemical Analysis） | pH、蛋白质、葡萄糖、酮体、胆红素、尿胆原、尿胆素、亚硝酸盐等 |
| 有形成分分析（Urine Sediment Examination） | 红细胞、白细胞、上皮细胞、吞噬细胞、管型、结晶等 |

### 1. 尿量（Urine Volume）

**正常值**

- 成人：约1,000～2,000 mL/24 h。
- 老师提供按体重估算约1 mL/(kg·h)。
- 儿童按单位体重计算，尿量约为成人的3～4倍。
- 昼夜尿量之比：约（2～4）:1。

**（1）少尿（Oliguria）**

【概念】成人24小时尿量少于400 mL，或每小时尿量少于约17 mL，称为少尿。

- 生理性少尿：大量出汗、饮水不足、体液丢失等。
- 病理性少尿：
  - 肾前性（Prerenal）：有效循环血量减少、肾灌注不足。
  - 肾性（Renal/Intrinsic）：各种肾实质疾病。
  - 肾后性（Postrenal）：尿路梗阻。

**（2）无尿（Anuria）**

成人24小时尿量少于100 mL，称为无尿，也称尿闭。

**（3）多尿（Polyuria）**

- 成人：24小时尿量超过2,500 mL。
- 课堂提到儿童24小时尿量超过3,000 mL；儿童临床判断通常更应结合年龄、体重及体表面积。

生理性多尿见于饮水量增加等情况；病理性多尿可见于肾小管重吸收障碍、肾浓缩功能减退等。

### 2. 尿液气味（Urine Odor）

正常新鲜尿液具有轻微的特殊芳香气味。

| 特殊气味 | 可能的临床原因 |
|---|---|
| 氨臭味（Ammoniacal Odor） | 慢性膀胱炎、尿潴留，尿液久置时也可出现 |
| 腐臭味（Putrid Odor） | 泌尿系统感染、晚期膀胱癌伴坏死等 |
| 烂苹果味或水果味（Fruity Odor） | 糖尿病酮症酸中毒（DKA），与丙酮有关 |
| 大蒜样气味（Garlic-like Odor） | 某些有机磷中毒 |
| 鼠尿味、霉臭味（Mousy/Musty Odor） | 苯丙酮尿症（Phenylketonuria, PKU） |

【临床关联】尿液气味可以提供初步诊断线索，但不能单凭气味确诊疾病。

### 3. 尿液颜色及透明度（Color and Clarity）

**正常尿液**：淡黄色、清晰透明。

生理性变化：

- 大量饮水、寒冷导致尿量增多：尿色变浅。
- 饮水不足、运动、出汗：尿液浓缩，颜色加深。
- 摄入大量胡萝卜、木瓜等：可能使尿色偏深黄或橙黄。
- 某些食物和药物可使尿呈红色或其他颜色。

**病理性颜色变化**

| 尿液颜色 | 常见原因 |
|---|---|
| 红色、淡红色 | 血尿、血红蛋白尿、肌红蛋白尿、食物或药物所致假性血尿 |
| 深黄色、黄褐色 | 胆红素尿、尿液高度浓缩 |
| 乳白色、灰白色 | 乳糜尿、脓尿、结晶尿 |
| 黑褐色、酱油色 | 严重血红蛋白尿、肌红蛋白尿、黑尿酸症、黑色素相关疾病、酚中毒等 |
| 紫色、蓝紫色 | 紫色尿袋综合征（Purple Urine Bag Syndrome） |
| 蓝绿色或铜绿色 | 铜绿假单胞菌感染等 |

【术语纠正】“尿布染染综合征”应为**紫色尿袋综合征**，主要见于部分长期留置导尿管的患者。<Cite ref="turn226131search0"/>

#### 红色尿的鉴别

【重点】红色尿不等于血尿，必须鉴别血尿、血红蛋白尿、肌红蛋白尿和假性血尿。

| 鉴别项目 | 血尿 Hematuria | 血红蛋白尿 Hemoglobinuria | 肌红蛋白尿 Myoglobinuria | 假性血尿 |
|---|---|---|---|---|
| 主要原因 | 泌尿生殖系统出血 | 血管内溶血 | 横纹肌损伤 | 药物、食物等色素 |
| 外观 | 淡红、洗肉水样，可见血凝块 | 暗红、棕红、酱油色 | 粉红、红褐色 | 红色或葡萄酒色 |
| 镜检红细胞 | 增多 | 通常无或极少 | 通常无或极少 | 无 |
| 离心上清 | 通常变清或颜色明显减轻 | 仍有红色 | 仍有红色 | 仍保持色素颜色 |
| 尿潜血反应 | 常阳性 | 阳性 | 阳性 | 通常阴性 |
| 尿蛋白 | 可随出血程度不同而变化 | 可阳性 | 可阳性 | 通常阴性 |

【易错】尿潜血试带检测的是血红素的过氧化物酶样活性，**血红蛋白和肌红蛋白也可使潜血呈阳性**，因此不能依赖潜血试带区分三者，必须结合尿沉渣镜检和临床表现。<Cite ref="turn226131search0"/>

#### 白色尿的鉴别

**（1）乳糜尿（Chyluria）**

由于泌尿系统淋巴管破裂、淋巴回流受阻，使淋巴液或乳糜液进入尿液。

- 外观：乳白色、乳状浑浊，可出现凝块，具有一定光泽。
- 常见于丝虫病（Filariasis）。
- 也可见于结核、肿瘤、肾病综合征、肾小管疾病、胸腹部创伤或肾周淋巴循环障碍等。

**（2）脓尿（Pyuria）**

尿液中含大量白细胞或脓细胞。

- 外观呈黄色、黄白色或白色浑浊。
- 静置后可能出现云絮状白色沉淀。
- 常见于肾盂肾炎、膀胱炎、前列腺炎、精囊炎、尿道炎等化脓性感染。

**（3）结晶尿（Crystalluria）**

尿液中存在大量盐类结晶，尤其是非晶形磷酸盐、碳酸盐等。

- 外观可呈黄白、灰白或淡粉红色。
- 需通过尿沉渣显微镜检查确定结晶成分。

### 4. 尿比重（Urine Specific Gravity, USG）

正常参考：

- 随机尿：约1.015～1.025。
- 晨尿：常大于1.020。

**（1）高比重尿**

课堂以比重大于1.025作为高比重尿参考。

可能原因：

- 脱水、高热、大量出汗。
- 急性肾炎、肝脏疾病、心力衰竭、外周循环衰竭。
- 糖尿病伴尿糖增多。
- 使用含碘造影剂、右旋糖酐等。

**（2）低比重尿**

课堂以比重小于1.015作为低比重尿参考。

- 尿崩症（Diabetes Insipidus）可引起明显低比重尿。
- 肾小管浓缩功能减退时，也可出现低比重尿。

**（3）等渗尿或固定低比重尿（Isosthenuria）**

【重要概念】尿比重长期固定在约1.010±0.003，接近肾小球滤液比重，提示肾脏调节尿液浓度的能力显著受损，尤其见于较严重的肾小管功能障碍。

药物还可能干扰比重测定。老师提到右旋糖酐、造影剂、蔗糖可使比重增高，而氨基糖苷类、锂剂、甲氧氟烷等药物可通过肾损伤或浓缩功能障碍引起低比重尿。

## 四、尿液化学检查（Urine Chemical Analysis）

目前主要采用**尿干化学分析仪及试带法（Urine Dipstick Analysis）**。

### 1. 尿液酸碱度（Urinary pH）

pH是氢离子活度的负对数。

正常饮食下：

- 尿液通常呈弱酸性。
- 常见pH为5.5～6.5。
- 平均约6.0。
- 随机尿pH可在4.5～8.0之间变化。

尿pH受到饮食、代谢、肾脏排酸以及尿路细菌等因素影响。

### 2. 尿蛋白（Urinary Protein）

**（1）正常蛋白滤过与重吸收**

肾小球滤过屏障（Glomerular Filtration Barrier）包括：

- 孔径或大小选择性屏障（Size Barrier）
- 电荷选择性屏障（Charge Barrier）

正常情况下，少量小分子蛋白可以滤过，大部分被近端肾小管（Proximal Tubule）重吸收。

课堂给出的参考值：

- 尿蛋白定性检查：阴性。
- 24小时尿蛋白定量：正常人约80 mg/24 h。
- 老师将超过120 mg/24 h列为蛋白尿参考。

【数值校核】目前常用临床判定是24小时尿总蛋白**超过150 mg**提示蛋白尿。课堂中“120～150 mg为轻度蛋白尿、500～4,000 mg为中度蛋白尿”存在150～500 mg的空档，不宜作为完整统一分级记忆。KDIGO使用总蛋白排泄量低于150、150～500和超过500 mg/日等分层；肾病范围蛋白尿常以超过3.5 g/日为参考。应区分老师课堂口径与现行临床分类。<Cite ref="turn675722search1"/>

**（2）生理性蛋白尿（Physiological Proteinuria）**

<text weight="medium">【可能考名词解释】功能性蛋白尿（Functional Proteinuria）</text>

由剧烈运动、发热、紧张等应激状态引起的一过性蛋白尿，常见于青少年。

特点：

- 多为轻度蛋白尿。
- 尿蛋白定性常不超过（+）。
- 刺激因素消失后一般恢复正常。

**体位性蛋白尿（Orthostatic/Postural Proteinuria）**

- 直立时出现，卧位或休息后消失。
- 可与脊柱前凸体位有关。
- 多为轻至中度蛋白尿。
- 常见于瘦高体型青少年。
- 又称直立性蛋白尿。

**（3）病理性蛋白尿（Pathological Proteinuria）**

可根据来源分为肾前性、肾性和肾后性蛋白尿。

#### ① 肾前性蛋白尿——溢出性蛋白尿

<text weight="medium">【可能考名词解释】溢出性蛋白尿（Overflow Proteinuria）</text>

血浆中某种低分子量蛋白异常增多，滤过负荷超过肾小管重吸收能力，使大量蛋白进入尿液。

- 以小分子蛋白为主。
- 课堂所述尿蛋白定性常为（+）至（++）。

主要类型及疾病：

- 本周蛋白（Bence Jones Protein）：浆细胞骨髓瘤、多发性骨髓瘤及相关单克隆免疫球蛋白疾病。
- 血红蛋白（Hemoglobin）：血管内溶血，如阵发性睡眠性血红蛋白尿（Paroxysmal Nocturnal Hemoglobinuria, PNH）。
- 肌红蛋白（Myoglobin）：挤压综合征、急性横纹肌损伤，部分心肌损伤状态。
- 某些酶类蛋白增多：急性单核细胞性或粒-单核细胞性白血病、胰腺炎等可出现相关蛋白或酶排泄异常。

#### ② 肾小球性蛋白尿（Glomerular Proteinuria）

肾小球滤过屏障的通透性增高或电荷选择性受损，使大量血浆蛋白进入原尿，超过肾小管的重吸收能力。

特点：

- 以白蛋白（Albumin）为主。
- 可含其他中高分子量蛋白。
- 课堂提及尿蛋白常超过2 g/24 h，但具体程度取决于疾病类型和严重程度。

原发性疾病：

- 肾小球肾炎（Glomerulonephritis）
- 肾病综合征（Nephrotic Syndrome）

继发性疾病：

- 糖尿病肾病（Diabetic Kidney Disease）
- 高血压相关肾损伤
- 系统性红斑狼疮（Systemic Lupus Erythematosus, SLE）相关肾炎

#### ③ 肾小管性蛋白尿（Tubular Proteinuria）

近端肾小管损伤导致其对滤过蛋白的重吸收功能下降。

特点：

- 常为轻度蛋白尿。
- 小分子蛋白比例增高，如α₁-微球蛋白（α₁-Microglobulin）和β₂-微球蛋白（β₂-Microglobulin）。
- 课堂提到白蛋白占比通常较低，可小于25%。

常见病因：

- 肾小管间质性肾炎。
- 重金属、苯类有机溶剂中毒。
- 肾毒性药物所致肾小管损伤。
- 肾移植后排斥反应。

#### ④ 混合性蛋白尿（Mixed Proteinuria）

肾小球和肾小管同时受到损伤，既有滤过屏障异常，又有蛋白重吸收障碍。

如糖尿病肾脏损伤、狼疮性肾炎以及其他累及多个肾单位结构的疾病。

#### ⑤ 肾后性蛋白尿（Postrenal Proteinuria）

蛋白来源于肾脏以下尿路或邻近组织的炎症、出血及分泌物。

常见于：

- 泌尿生殖系统炎症。
- 泌尿系结石。
- 泌尿系统结核、肿瘤。
- 邻近器官炎症，如急性阑尾炎等。

【易错】尿干化学试带主要对**白蛋白**敏感，对某些低分子量蛋白，尤其游离轻链，可能不敏感。怀疑溢出性蛋白尿时，应结合尿蛋白定量、尿蛋白电泳或免疫固定等进一步检查。<Cite ref="turn226131search0"/>

### 3. 尿糖（Urinary Glucose / Glycosuria）

尿液中的糖以葡萄糖为主，也可有微量乳糖、半乳糖、果糖等。

正常人尿中可存在极少量葡萄糖，但常规方法检测结果通常为阴性。

老师提到血糖超过约8.88 mmol/L时，尿液开始出现葡萄糖。

【数值补充】肾糖阈存在个体差异，常用近似值为血糖180 mg/dL，即约10 mmol/L，不能将8.88 mmol/L视为人人固定的阈值。<Cite ref="turn226131search0"/>

**尿糖增高的类型**

- 代谢性糖尿：如糖尿病（Diabetes Mellitus）。
- 内分泌性糖尿：如甲状腺功能亢进引起的血糖升高。
- 肾性糖尿（Renal Glycosuria）：近端肾小管葡萄糖重吸收障碍，可在血糖正常时出现尿糖。
- 暂时性糖尿（Transient Glycosuria）：大量摄入糖类、碳水化合物饮料，或静脉输入葡萄糖后。
- 应激性糖尿：情绪激动、脑血管意外、颅脑外伤、脑出血、急性心肌梗死等应激状态。

【临床关联】一过性尿糖增高可以自行恢复；目前使用SGLT2抑制剂的患者也可能在血糖不高时出现尿糖阳性，需要结合用药史解释。

### 4. 尿酮体（Urinary Ketone Bodies）

酮体（Ketone Bodies）是脂肪氧化代谢产生的中间产物，包括：

1. 乙酰乙酸（Acetoacetate）
2. β-羟丁酸（β-Hydroxybutyrate, BHB）
3. 丙酮（Acetone）

【术语纠正】转写中的“β-丙酮”应为“丙酮”。

**形成机制**

当葡萄糖利用障碍或脂肪分解明显增多时：

脂肪分解增强 → 肝脏酮体生成增加 → 酮体产生超过组织利用能力 → 酮血症（Ketonemia）→ 酮体经尿液排出，形成酮尿（Ketonuria）。

正常尿酮体定性检查为阴性。

**糖尿病性酮尿**

- 糖尿病酮症（Diabetic Ketosis）。
- 糖尿病酮症酸中毒（Diabetic Ketoacidosis, DKA）。
- 老师还提到双胍类降糖药物相关的代谢异常；但需注意，双胍类药物最典型的严重代谢风险是乳酸性酸中毒，不能据此将用药等同于酮症酸中毒。

**非糖尿病性酮尿**

- 长期饥饿。
- 高热。
- 严重呕吐。
- 肝硬化、严重肝功能障碍。
- 某些肿瘤或其他消耗性疾病。

部分药物和标本条件可能干扰检测，尿液久置也可能导致检验结果失真。

【易错】常规硝普盐尿酮体试带主要检出乙酰乙酸，对β-羟丁酸不敏感，因此严重酮症酸中毒时，不能仅依据尿酮体程度判断病情。<Cite ref="turn226131search0"/>

### 5. 尿胆红素、尿胆原与尿胆素

涉及的主要物质：

- 尿胆红素（Urinary Bilirubin）
- 尿胆原（Urobilinogen）
- 尿胆素（Urobilin）

**形成及排泄**

结合胆红素（Conjugated Bilirubin）具有水溶性，血中浓度升高时可以通过肾脏排泄。

非结合胆红素（Unconjugated Bilirubin）主要与白蛋白结合，通常不能直接经肾小球滤过。

正常情况下：

- 尿胆红素：阴性。
- 尿胆原：可有微量，定性试验阴性或弱阳性。
- 老师提到尿胆原1:20稀释试验作为传统鉴别方法。

【重点】三种黄疸的尿液检验鉴别。

| 检查项目 | 正常 | 溶血性黄疸 | 肝细胞性黄疸 | 梗阻性黄疸 |
|---|---|---|---|---|
| 尿液颜色 | 淡黄、清晰 | 可加深 | 深黄色 | 深黄色 |
| 尿胆原 | 少量/弱阳性 | 显著增多 | 常增多，随病情变化 | 减少或阴性 |
| 尿胆素 | 少量或阴性 | 常阳性 | 常阳性 | 减少或阴性 |
| 尿胆红素 | 阴性 | 阴性 | 阳性 | 阳性 |

**鉴别原理**

- 溶血性黄疸（Hemolytic Jaundice）：胆红素生成增加，尿胆原增多，但尿胆红素通常阴性。
- 肝细胞性黄疸（Hepatocellular Jaundice）：肝细胞摄取、结合、排泄胆红素的功能受损，可出现尿胆红素阳性；尿胆原可增多。
- 梗阻性黄疸（Obstructive Jaundice）：结合胆红素返流入血，尿胆红素阳性，而进入肠道的胆红素减少，尿胆原减少甚至消失。

【易错】肝细胞性黄疸的尿胆原不一定始终为强阳性；严重肝内胆汁淤积时也可下降。表格反映课堂讲授的典型模式，而非所有病例的绝对规律。

### 6. 尿亚硝酸盐（Urinary Nitrite）

尿液中含有来源于食物及代谢过程的硝酸盐（Nitrate）。

某些细菌具有硝酸盐还原酶（Nitrate Reductase），能够将硝酸盐还原为亚硝酸盐（Nitrite）。

代表性细菌：大肠埃希菌（*Escherichia coli*）。

**正常结果：阴性。**

【临床意义】亚硝酸盐试验主要用于尿路感染（Urinary Tract Infection, UTI）的快速筛查。

【易错】亚硝酸盐阳性支持特定细菌感染，但阴性不能排除尿路感染。原因包括感染细菌不具有硝酸盐还原能力、膀胱内停留时间不足，以及尿液中硝酸盐不足等。<Cite ref="turn226131search0"/>

## 五、尿液有形成分分析（Urine Sediment Examination）

### 1. 细胞成分总分类

尿液中的主要细胞包括：

- 红细胞（Erythrocytes）：均一性及非均一性红细胞。
- 白细胞（Leukocytes）：完整中性粒细胞、脓细胞、闪光细胞。
- 吞噬细胞（Phagocytes）：大吞噬细胞、小吞噬细胞。
- 上皮细胞（Epithelial Cells）：肾小管上皮、移行上皮和鳞状上皮细胞。

### 2. 尿红细胞（Urinary Red Blood Cells）

正常红细胞为双凹圆盘状（Biconcave Disc），在尿沉渣中可呈淡黄色、中央较浅的圆形结构。

受尿液环境影响：

- 高渗尿：红细胞皱缩，表面可呈棘状。
- 低渗尿：吸水膨胀，血红蛋白逸出，可形成影红细胞（Ghost Cells）。

【易错】转写中的“红细胞带氧”，应为**影红细胞**。

#### 均一性红细胞血尿（Isomorphic Hematuria）

红细胞大小、形态较一致，血红蛋白含量基本正常，与外周血红细胞相近。

主要见于非肾小球源性血尿（Nonglomerular Hematuria），即肾小球以下泌尿系统出血。

#### 非均一性红细胞血尿（Dysmorphic Hematuria）

尿中红细胞大小差异明显，可出现多种异常形态：

- 棘形、棘突红细胞（Acanthocytes）。
- 皱缩型。
- 面包圈样。
- 芽孢样。
- 哑铃形。
- 红细胞碎片。

课堂提到：异形红细胞比例大于70%，且存在两种以上不同异常形态时，可按课堂判定口径考虑非均一性红细胞血尿。

主要提示肾小球源性血尿（Glomerular Hematuria）。

【临床关联】肾小球滤过屏障损伤后，红细胞在穿过肾单位过程中发生机械性变形；棘形红细胞具有较高的肾小球来源提示价值。

【易错】形态阈值受镜检方法及实验室标准影响，不宜将课堂“70%”用于所有实验室。应特别结合棘形红细胞比例、红细胞管型、蛋白尿及肾功能综合判断。

### 3. 尿白细胞（Urinary White Blood Cells）

**完整白细胞**

新鲜尿中常见中性粒细胞（Neutrophils）：

- 形态完整。
- 胞质内有颗粒。
- 分叶核清楚。
- 多散在分布。
- 少量可见淋巴细胞（Lymphocytes）和单核细胞（Monocytes）。

**脓细胞（Pus Cells）**

为破坏或死亡的中性粒细胞：

- 形态不规则。
- 核及细胞结构模糊。
- 胞质出现粗大颗粒。
- 常成团聚集，细胞间界限不清。

【识图】老师展示完整白细胞与脓细胞的对比：脓细胞出现明显变形、破裂和成团分布。

酸处理尿沉渣可使红细胞破坏，有利于观察保留下来的白细胞核结构，例如分叶核中性粒细胞。

**闪光细胞（Glitter Cells）**

低渗尿液中的中性粒细胞吸水膨胀，胞质颗粒出现明显布朗运动（Brownian Motion），显微镜下呈闪光样运动。

【术语纠正】它不是“脂肪化的白细胞”，而主要与细胞膨胀及胞质颗粒运动有关。

### 4. 尿吞噬细胞（Urinary Phagocytes）

分为大、小两类。

**大吞噬细胞（Macrophages）**

- 主要来源于单核-巨噬细胞系统。
- 体积较大，胞质丰富。
- 核可呈肾形或不规则形。
- 胞质内常有空泡、吞噬颗粒。
- 细胞大小变化明显，课堂提到可达到数十微米，部分巨细胞更大。

**小吞噬细胞**

- 老师描述为由中性粒细胞转变形成。
- 常约10 μm。
- 胞质内可见吞噬物。

**临床意义**

尿中吞噬细胞增多可见于泌尿生殖系统炎症，常伴白细胞、脓细胞和细菌增多。其数量在一定程度上可反映炎症活动。

【识图】老师展示吞噬细胞胞质内充满颗粒和吞噬物的图像，并与较小的白细胞进行对比。

### 5. 尿上皮细胞（Urinary Epithelial Cells）

尿上皮细胞来源于肾小管至尿道口的泌尿道上皮脱落细胞。

**参考情况**

- 肾小管上皮细胞：正常尿中通常无。
- 移行上皮细胞：偶见。
- 鳞状上皮细胞：男性偶见；女性课堂参考约0～5个/高倍镜视野（HPF）。

#### （1）肾小管上皮细胞（Renal Tubular Epithelial Cells, RTECs）

来源于肾小管的立方上皮（Cuboidal Epithelium）。

特点：

- 略大于白细胞。
- 可为圆形、多边形或椭圆形。
- 圆形者俗称**小圆上皮细胞（Small Round Epithelial Cells）**。
- 胞核较大，圆形，核膜厚。
- 核质比（Nuclear-to-Cytoplasmic Ratio, N/C Ratio）较高。
- 胞质中常有粗大颗粒和小空泡。

近端肾小管上皮细胞：

- 体积相对较大。
- 课堂提到部分细胞直径可达20～60 μm。
- 可呈椭圆形、雪茄形。
- 细胞核有时偏位，偶可见多核。

【识图】老师特别强调肾小管上皮细胞的**大核、高核质比**特征。

展示的尿沉渣图片中还同时出现了草酸钙结晶、白细胞以及面包圈样变形红细胞，用于帮助区分不同有形成分。

#### （2）移行上皮细胞（Transitional/Urothelial Cells）

来源于肾盂、输尿管、膀胱及部分尿道的尿路上皮（Urothelium）。

按上皮层次分为：

| 类型 | 形态特点 | 来源及名称 |
|---|---|---|
| 表层移行上皮细胞 | 较大，圆形或不规则圆形；膀胱充盈状态下可达白细胞4～5倍；核相对较小、居中 | 膀胱等尿路表层；塌陷状态较小者常称大圆上皮细胞 |
| 中层移行上皮细胞 | 梨形、尾形，核较大、圆形或椭圆形 | 又称尾形上皮细胞（Caudate Cells），肾盂来源较典型 |
| 底层移行上皮细胞 | 相对较小，但常大于肾小管上皮细胞 | 输尿管、膀胱等尿路上皮底层 |

**临床意义**

正常尿中可无或偶见移行上皮细胞。若大量出现或成片脱落，提示尿路炎症、上皮损伤或坏死性病变，需要结合其他检查判断。

【识图】老师使用红色箭头指出尾形上皮细胞，强调其梨形及一端延长的形态。

#### （3）鳞状上皮细胞（Squamous Epithelial Cells）

来源于尿道远端及女性外阴、阴道表层的复层鳞状上皮（Stratified Squamous Epithelium）。

特点：

- 直径约40～60 μm。
- 大而扁平，似鱼鳞或薄石板。
- 胞质丰富，可见细小颗粒。
- 核较小，圆形或卵圆形，居中。
- 边缘可卷折，部分细胞可无核。

**临床意义**

- 女性因阴道分泌物混入，尿中可出现较多鳞状上皮细胞，常提示标本污染。
- 课堂还提到女性大量鳞状上皮细胞可能与雌激素水平较高有关，伴大量白细胞时可考虑妇科炎症。

【易错】鳞状上皮细胞增多最常首先考虑标本污染或脱落增加，**不能仅凭其数量判断雌激素水平或确诊妇科炎症**。

## 六、尿管型（Urinary Casts）

【重点】老师强调：**管型是尿沉渣中最有临床意义的成分之一。**

### 1. 管型的定义与形成条件

**管型（Urinary Cast）**是以尿蛋白为基础，在肾小管和集合管（Collecting Duct）腔内形成的圆柱形结构。

主要基质为Tamm–Horsfall蛋白，即尿调节素（Uromodulin, UMOD）。

形成条件：

1. 蛋白质及细胞成分析出或渗出。
2. 肾小管尿流缓慢、淤滞和尿液酸化。
3. 存在功能活动交替的肾单位，使部分管型能够在肾小管内形成及保留。

**管型分类**

- 透明管型（Hyaline Cast）
- 细胞管型（Cellular Cast）：红细胞、白细胞、上皮细胞及混合细胞管型
- 颗粒管型（Granular Cast）：粗颗粒、细颗粒管型
- 脂肪管型（Fatty Cast）
- 蜡样管型（Waxy Cast）
- 宽大管型（Broad Cast）
- 细菌、真菌及结晶管型等

### 2. 透明管型（Hyaline Cast）

主要由尿调节素、少量白蛋白及其他尿液成分组成。

形态：

- 无色、半透明。
- 形状比较规则。
- 两端钝圆。
- 内部结构较均匀。

出现情况：

- 正常晨尿少量可见。
- 运动、应激等情况下可增多。
- 肾小球肾炎、肾病综合征、肾盂肾炎。
- 肾毒性药物所致肾实质损伤。

**复合性透明管型**

老师介绍：

- 透明红细胞管型：提示肾内出血。
- 透明白细胞管型：提示肾脏炎症。
- 透明脂肪管型：可提示肾病综合征。

**鉴别标准**

- 当管型内包含的细胞或颗粒成分占总体积（或面积）不足1/3时，可仍按透明管型相关分类描述。
- 超过约1/3时，应根据主要内容物进一步归类为细胞管型、颗粒管型等。

### 3. 细胞管型（Cellular Cast）

#### （1）红细胞管型（Red Blood Cell Cast）

管型基质内有大量红细胞。

形态：

- 黄色或红褐色。
- 红细胞密集，可不完整。
- 易折断、碎裂。

部分红细胞退变后形成含血红蛋白色素的颗粒，可形成血红蛋白管型（Hemoglobin Cast）。

常见于：

- 急性肾小球肾炎。
- 慢性肾小球肾炎急性发作。
- 肾出血。
- 部分急性肾小管损伤。
- 肾移植后急性排斥反应。

【临床关联】红细胞管型尤其提示**出血发生在肾单位内**，是判断肾小球源性血尿的重要证据。

#### （2）白细胞管型（White Blood Cell Cast）

管型内含大量白细胞或脓细胞，细胞可发生退变。

- 未染色时较难与肾小管上皮细胞管型区分。
- 典型相关疾病为急性肾盂肾炎（Acute Pyelonephritis）、肾间质性炎症。
- 也可见于狼疮性肾炎及其他肾脏炎性疾病。

【易错】转写此处重复了上一段红细胞管型的疾病列表，属于明显的讲述或转写重复。白细胞管型的重点应是**肾小管间质及肾实质炎症**，而不是简单将红细胞管型的适应疾病照搬。

#### （3）肾小管上皮细胞管型（Renal Tubular Epithelial Cell Cast）

管型中有较多肾小管上皮细胞，可呈瓦片状排列。

- 细胞通常比白细胞大。
- 提示肾小管上皮损伤及脱落。

常见于：

- 急性肾小管坏死（Acute Tubular Necrosis, ATN）。
- 肾淀粉样变性（Renal Amyloidosis）。
- 重金属、化学毒物中毒。
- 肾移植急性排斥反应。

#### （4）混合细胞管型（Mixed Cellular Cast）

管型内同时出现两种或两种以上细胞。

可见于：

- 肾小球肾炎。
- 狼疮性肾炎（Lupus Nephritis）。
- 肾梗死、肾缺血性病变。
- 肾病综合征。

【临床关联】肾移植患者出现由上皮细胞和淋巴细胞组成的混合细胞管型，可提示急性排斥反应。

### 4. 颗粒管型（Granular Cast）

管型内颗粒占管型面积约1/3以上。

分为：

- 粗颗粒管型（Coarse Granular Cast）
- 细颗粒管型（Fine Granular Cast）

形成机制：

细胞成分或蛋白基质发生退变，形成颗粒；管型在肾单位中停留时间较长时，粗颗粒可进一步变为细颗粒。

老师还介绍一种传统解释：

- 粗颗粒可能与白细胞变性有关，过氧化物酶染色可呈阳性。
- 细颗粒可能与上皮细胞变性有关，可见部分相关酶染色阳性。

【识图】左图为粗颗粒，右图为细颗粒，重点比较颗粒大小与均匀程度。

### 5. 脂肪管型（Fatty Cast）

管型内含大量脂肪滴，当脂肪成分超过面积约1/3时，可称脂肪管型。

形成原因：肾小管上皮细胞脂肪变性、脂质沉积与脱落。

特点：

- 脂肪滴大小不等。
- 圆形，折光性强。
- 偏振光显微镜下可见**马耳他十字征（Maltese Cross）**。

常见于：

- 肾病综合征。
- 慢性肾小球肾炎急性发作。
- 其他伴脂质沉积的肾小管损伤。

【识图】老师展示了脂肪管型及偏振光下的马耳他十字现象。

### 6. 蜡样管型（Waxy Cast）

由长期滞留于肾小管内的细胞管型、颗粒管型等进一步变性形成。

特点：

- 折光性较强。
- 质地厚实，灰白色或淡黄色。
- 呈蜡烛样。
- 常有切迹、裂纹或扭曲。
- 边缘可较锐利。

常见于：

- 严重肾小管变性、坏死。
- 晚期肾小球肾炎。
- 肾衰竭。

### 7. 宽大管型（Broad Cast）

又称**肾衰管型（Renal Failure Cast）**。

- 形成于明显扩张、尿流缓慢的肾小管或集合管中。
- 由凝聚的蛋白及退化、坏死上皮细胞碎片组成。
- 直径约为普通管型的2～6倍。

常见于慢性肾衰竭及严重少尿等情况。

【临床意义】宽大管型通常提示严重的肾单位损伤，可能与预后不良有关。

### 8. 细菌管型和结晶管型

**细菌管型（Bacterial Cast）**

管型中含大量细菌，可能伴有白细胞；感染时也可见真菌相关管型。

主要提示肾实质感染。

**结晶管型（Crystal Cast）**

盐类结晶附着于尿调节素基质形成。

- 结晶形态可能不规则，种类不易辨认。
- 可见于大量磷酸盐类等结晶析出。
- 部分情况下与结晶相关肾损伤有关。

### 9. 类管型结构的鉴别

【易错】不是所有圆柱形物体都是真正的尿管型。

| 结构 | 形态特征 | 意义 |
|---|---|---|
| 类圆柱体（Cylindroids） | 类似透明管型，但一端细长、尖细或呈螺旋状 | 可与透明管型同时出现，见于肾脏受刺激、血流变化等 |
| 黏液丝（Mucus Threads） | 长条状，边缘不清，末端纤细、弯曲 | 少量可正常存在，女性尿中较常见；大量出现可见于尿道炎症 |
| 假管型（Pseudocasts） | 黏液丝上黏附非晶形尿酸盐或磷酸盐形成的假圆柱体 | 易与颗粒管型混淆 |

**鉴别原则：**结合两端形态、内部基质、颗粒分布及是否具有真正的圆柱形轮廓判断。

## 七、尿液结晶（Urinary Crystals）

### 1. 结晶的基本分类

**（1）生理性结晶（Physiological Crystals）**

与尿液正常代谢产物、饮食及尿pH有关。

- 酸性尿：尿酸结晶、草酸钙结晶等。
- 碱性尿：磷酸盐、碳酸盐类结晶。

少量生理性结晶通常没有特殊临床意义，但大量结晶析出仍可能导致结石或肾损伤。

**（2）病理性结晶（Pathological Crystals）**

出现于特定病理或代谢异常状态。

主要包括：

- 胱氨酸结晶（Cystine Crystals）
- 酪氨酸结晶（Tyrosine Crystals）
- 亮氨酸结晶（Leucine Crystals）
- 胆红素结晶（Bilirubin Crystals）
- 胆固醇结晶（Cholesterol Crystals）

酪氨酸、亮氨酸结晶与严重组织坏死、重症肝病等有关；胱氨酸结晶与胱氨酸代谢或转运异常有关。

**（3）药物性结晶（Drug-induced Crystals）**

以磺胺类结晶（Sulfonamide Crystals）为代表。

在酸性尿中更容易析出，部分药物结晶可造成：

- 少尿、无尿。
- 血尿。
- 肾绞痛。
- 结晶性肾病及尿路结石。

老师还介绍磺胺类结晶可能通过特定化学试剂及溶解特性进行鉴别。

### 2. 草酸钙结晶（Calcium Oxalate Crystals）

【识图重点】人体尿液中最常见的结晶之一。

**二水草酸钙（Calcium Oxalate Dihydrate, COD）**

- 八面体形。
- 光镜下呈典型的**信封样（Envelope-shaped）**。
- 轮廓清楚，中央有交叉线。

**一水草酸钙（Calcium Oxalate Monohydrate, COM）**

形态变化较多：

- 椭圆形。
- 小球形。
- 哑铃形（Dumbbell-shaped）。
- 稻草捆形等。

【识图】老师展示二水草酸钙的信封样结构，以及椭圆形、哑铃形的一水草酸钙。

### 3. 尿酸结晶（Uric Acid Crystals）

为形态变化较多的尿液结晶。

- 多见于酸性尿。
- 可呈黄色、棕黄色、暗棕色。
- 有时肉眼可见铁锈色砂粒样沉淀。

常见形态：

- 菱形、斜方形。
- 三棱形。
- 哑铃形。
- 蝴蝶形。
- 玫瑰花形。

【识图】老师展示典型尿酸结晶及花朵状尿酸结晶，强调其**颜色和多变的晶体形态**。

### 4. 磷酸铵镁结晶（Magnesium Ammonium Phosphate Crystals）

又称：

- 三联磷酸盐结晶（Triple Phosphate Crystals）
- 鸟粪石结晶（Struvite Crystals）

【术语纠正】此处转写中的“黄铵类结晶”应为**磷酸铵镁结晶**，不是前面提到的磺胺类药物结晶。

形态：

- 无色，折光性较强。
- 大小不一。
- 典型呈棱柱形、棺盖状（Coffin-lid Appearance）。
- 可呈星形、漏斗形等变异形态。

【识图】老师将其比喻为房屋屋顶的形状，帮助记忆典型棺盖状结构。

### 5. 胆红素结晶（Bilirubin Crystals）

病理性结晶。

- 呈针状、束状、小块状。
- 橘红色、黄褐色。
- 氧化后也可呈非晶形色素颗粒。

化学特性：

- 加硝酸氧化后，可出现与胆绿素相关的绿色变化。
- 可溶于氢氧化钠或氯仿等适当溶剂。

常见于：

- 急性黄疸性肝病。
- 重症肝功能损伤。
- 肝硬化、肝癌。
- 某些中毒或伴胆红素代谢异常的疾病。

### 6. 胱氨酸结晶（Cystine Crystals）

典型特征：

- 无色。
- **六边形薄片状（Hexagonal Plates）**。
- 折光性较强。
- 可重叠、成堆出现。

【临床意义】大量胱氨酸结晶提示胱氨酸尿症（Cystinuria）的可能，并与胱氨酸结石有关。

### 7. 胆固醇结晶（Cholesterol Crystals）

- 无色。
- 方形薄片状。
- 典型表现为**缺角的平板状晶体（Notched Rectangular Plates）**。
- 可漂浮于尿液表面。

见于肾脏脂质异常、肾病综合征、肾淀粉样变性及某些泌尿道炎症等。

### 8. 酪氨酸结晶（Tyrosine Crystals）

- 细针状。
- 可呈束状或羽毛状排列。
- 课堂描述为颜色较深的针状结晶。

见于：

- 急性肝坏死。
- 重症肝炎。
- 严重组织坏死。
- 某些急性中毒状态。

### 9. 亮氨酸结晶（Leucine Crystals）

- 淡黄色小球形。
- 油滴状。
- 折光性强。
- 有辐射状或同心圆纹理。

可见于：

- 急性肝坏死。
- 严重肝功能障碍。
- 严重组织分解及代谢紊乱。
- 老师还列举糖尿病昏迷、白血病、伤寒和某些中毒状态。

### 10. 磺胺类结晶（Sulfonamide Crystals）

- 棕黄色。
- 不对称。
- 可呈麦秆束状或球状。

【临床关联】服用磺胺类药物后，如新鲜尿液中出现大量磺胺结晶，同时伴红细胞或管型，应警惕药物相关结晶性肾损伤。

### 11. 结晶综合识图与鉴别

老师接着连续展示多组显微镜图像，重点对比：

- 酪氨酸：细针状、成束。
- 胱氨酸：六边形薄片。
- 胆固醇：方形缺角薄片。
- 胆红素：黄褐或橘黄色针状。
- 二水草酸钙：信封形。
- 一水草酸钙：椭圆形、哑铃形。

【易错】椭圆形一水草酸钙结晶可能与尿红细胞混淆。

鉴别：

- 一水草酸钙：折光性更强，晶体轮廓比较清楚。
- 红细胞：折光性较弱，常可辨认中央淡染区，且可能受尿液渗透压影响而膨胀或皱缩。

# 九、粪便检验（Fecal Examination）

## 1. 粪便的组成与检查目的

粪便（Feces/Stool）主要由以下物质组成：

- 未被吸收的食物残渣。
- 消化道分泌物。
- 脱落的消化道黏膜细胞。
- 细菌及其他微生物。
- 无机盐及水。

**粪便检验的临床用途**：辅助诊断和筛查消化系统炎症、出血、寄生虫感染及肿瘤等疾病，同时评价部分消化吸收功能。

检查分为三部分：

| 类别 | 内容 |
|---|---|
| 外观和理学参数 | 粪便量、性状、颜色、气味 |
| 化学分析 | 粪便隐血试验等 |
| 有形成分分析 | 细胞、食物残渣、结晶、微生物、寄生虫 |

## 十、粪便外观和理学检查

### 1. 粪便量（Stool Volume）

正常成人排便次数存在个体差异，每日1次较常见。

- 每日粪便量约100～300 g。
- 与进食种类、摄入量、胃肠道运动及消化吸收功能有关。

老师提到：

- 上段肠道疾病：部分情况下排便次数减少、每次排便量增多。
- 下段肠道疾病：可表现为排便次数增多、每次排便量减少。

这些属于可能的临床表现，不能仅凭次数与排量定位病变。

### 2. 粪便性状（Stool Consistency）

| 异常粪便性状 | 主要形成机制 | 常见疾病 |
|---|---|---|
| 球形硬块便（Scybalous Stool） | 粪便在肠道停留过久，水分吸收过多 | 便秘、老年人排便困难、经产妇排便无力、先天性巨结肠 |
| 黏液便（Mucous Stool） | 肠黏膜受炎症、刺激或过敏影响，黏液分泌增加 | 各类肠炎、细菌性痢疾、阿米巴痢疾、急性血吸虫病 |
| 鲜血便（Hematochezia） | 多为下消化道或肛直肠出血 | 肛裂、痔、直肠息肉、直肠癌、结肠癌 |
| 脓便、脓血便（Purulent/Bloody Purulent Stool） | 肠道炎症、感染、溃疡或肿瘤坏死 | 细菌性痢疾、阿米巴痢疾、溃疡性结肠炎、克罗恩病、肠结核、肠癌、血吸虫病 |
| 柏油样便（Melena） | 血液在消化道内发生消化、氧化 | 多见于上消化道出血，如消化性溃疡 |
| 稀糊状便（Mushy Stool） | 肠蠕动增强，水分吸收减少或分泌增多 | 感染性、非感染性腹泻 |
| 米泔水样便（Rice-water Stool） | 霍乱肠毒素引起肠道大量分泌水和电解质 | 霍乱 |
| 白陶土样便（Clay-colored Stool） | 胆汁进入肠道减少，粪胆素生成不足 | 梗阻性黄疸 |
| 果冻样、胶冻样便（Jelly-like Stool） | 黏液分泌异常，可与肠痉挛、肠道功能紊乱有关 | 肠易激综合征等，亦须鉴别肠套叠等疾病 |
| 乳凝块状便（Curdy Stool） | 脂肪及酪蛋白消化不完全 | 婴儿消化不良、腹泻 |
| 细条状便、铅笔样便（Pencil-thin Stool） | 肠腔狭窄或排便性状改变 | 直肠狭窄、部分直肠肿瘤等 |

【术语纠正】转写中“局限性肠炎”可对应克罗恩病（Crohn Disease）；“条状便”也可称铅笔样便。

【易错】老师讲述鲜血便时出现“上消化道出血”的口误。这里应以**下消化道出血**为典型，但快速大量上消化道出血也可能出现鲜血便。柏油样便则更典型地与上消化道出血有关。

### 3. 粪便颜色（Stool Color）

**正常粪便**

- 成人：黄褐色、质软、成形，具有特殊臭味。
- 婴儿：可为黄色或金黄色的稀糊状便。

不同颜色的非病理性与病理性原因：

| 颜色 | 食物、药物等原因 | 病理原因 |
|---|---|---|
| 鲜红色 | 大量西红柿、西瓜、红色色素 | 下消化道出血、痔、肛裂、结直肠癌 |
| 暗红色 | 某些深色食物、咖啡、可可、巧克力等可改变粪色 | 阿米巴痢疾、肠道出血及其他肠道病变 |
| 灰白色 | 钡餐、硫酸钡、部分药物及大量脂肪 | 胆道梗阻、脂肪消化吸收异常等 |
| 绿色 | 大量绿色蔬菜、部分食品或药物 | 婴儿肠炎、肠道转运增快，胆绿素未充分转化 |
| 黑色 | 铁剂、动物血、动物肝脏、活性炭及部分中药 | 上消化道出血 |
| 淡黄色 | 婴儿便、部分泻药如大黄 | 脂肪消化不完全、胆色素代谢变化 |

**颜色变化的机制**

胆红素进入肠道后，在肠道微生物作用下转化为尿胆原等物质，并进一步生成粪胆素（Stercobilin），使粪便呈棕黄色。

胆道梗阻时，进入肠腔的胆色素减少，粪胆素形成不足，可出现灰白色或白陶土样便。

## 十一、粪便化学分析——隐血试验

### 1. 隐血的定义

**粪便隐血（Fecal Occult Blood, FOB）**是指消化道少量出血，肉眼不能直接发现，常规粪便镜检也不能明确证实，而需要通过专门方法检测的血液成分。

**粪便隐血试验（Fecal Occult Blood Test, FOBT）**

主要用于：

- 消化道隐匿性出血的筛查。
- 消化性溃疡等出血性病变的辅助诊断。
- 消化道肿瘤相关出血的筛查。
- 部分消化道疾病治疗过程中的出血监测。

健康人常规隐血检查通常为阴性。

阳性可见于：

- 胃黏膜损伤。
- 胃溃疡、十二指肠溃疡。
- 溃疡性结肠炎。
- 钩虫感染。
- 消化道恶性肿瘤。
- 药物相关胃肠黏膜损伤。

### 2. 消化性溃疡与恶性肿瘤的鉴别

老师介绍一种传统经验：

- 消化性溃疡：隐血可能呈**间断性阳性**，治疗好转后可转阴。
- 消化道恶性肿瘤：隐血可能呈**持续性阳性**。

【临床注意】该规律只是辅助线索。肿瘤出血也可能间歇发生，隐血阴性不能排除肿瘤，持续阳性亦不能直接确诊恶性肿瘤。

### 3. 化学法与免疫法

#### （1）化学法（Guaiac-based/Chemical FOBT）

老师重点介绍传统邻联甲苯胺法（o-Tolidine Test），利用血红素的过氧化物酶样活性检测粪便中的血液成分。

课堂提到其可检出一定程度的消化道出血，并举出约5～10 mL出血量的传统参考描述。实际灵敏度受样本、方法及试剂影响。

**优点**

- 操作简单。
- 成本低。
- 易于开展。

**缺点**

- 特异性相对较差。
- 受饮食与药物干扰较明显。
- 灵敏度依检测方法而异。

**假阳性**

- 进食动物血、部分红肉。
- 某些具有过氧化物酶活性的生蔬菜。
- 其他非目标来源的血液污染。

**假阴性**

- 大剂量维生素C（Vitamin C/Ascorbic Acid）。
- 某些还原性药物。
- 血红素发生降解，或血液在胃肠道内停留过久。

#### （2）免疫法（Fecal Immunochemical Test, FIT）

采用抗人血红蛋白抗体识别粪便中的人血红蛋白，部分胶体金法采用双抗体夹心免疫测定（Sandwich Immunoassay）。

【术语纠正】转写中“抗人血红蛋白脂质抗体”应理解为标记抗人血红蛋白抗体，而不是“脂质抗体”。

**优点**

- 操作方便、快速。
- 对人血红蛋白特异性较高。
- 灵敏度较高。
- 一般不需要限制饮食。

**局限**

- 胃肠道少量非病变性出血也可能产生阳性。
- 血红蛋白在上消化道被消化、抗原表位破坏，可导致假阴性。
- 阳性不能说明出血的确切病因。

【易错】FIT对下消化道出血的检测更有优势，通常不能替代上消化道出血检查。化学法与免疫法对饮食干扰的敏感程度不同。<Cite ref="turn675722search7"/>

## 十二、粪便有形成分分析（Fecal Microscopy）

直接涂片镜检可观察：

- 红细胞、白细胞和吞噬细胞。
- 淀粉、脂肪滴、肌肉及植物纤维等食物残渣。
- 结晶。
- 细菌、真菌。
- 寄生虫卵和肠道原虫。

### 1. 粪便白细胞（Fecal Leukocytes）

正常粪便中白细胞可偶见，主要为中性粒细胞。

肠道发生炎症时白细胞增多，其数量及分布与病变程度、部位和性质有关。

老师提到部分炎症情况下白细胞可少于15个/高倍镜视野，而较重的炎症可见大量白细胞聚集。

**不同疾病特点**

- 小肠炎症：白细胞与粪便混合比较均匀，由于消化酶等作用，细胞形态可能难以辨认。
- 细菌性痢疾、阿米巴痢疾、溃疡性结肠炎：可见大量白细胞或脓细胞。
- 过敏性肠炎、肠道寄生虫感染：可能出现较多嗜酸性粒细胞（Eosinophils），常伴夏科-莱登结晶（Charcot–Leyden Crystals）。

【识图】老师展示粪便白细胞的颗粒状胞质及细胞核，并与体积更小、无胞质颗粒的红细胞对比。

### 2. 粪便红细胞（Fecal Erythrocytes）

正常粪便中一般不应检出红细胞。

红细胞增多见于：

- 下消化道炎症及出血。
- 溃疡性结肠炎。
- 急性血吸虫病。
- 结直肠癌、直肠息肉。
- 细菌性痢疾、阿米巴痢疾。
- 痔出血等。

**细菌性痢疾与阿米巴痢疾的镜检区别**

| 项目 | 细菌性痢疾 | 阿米巴痢疾 |
|---|---|---|
| 白细胞 | 通常明显增多 | 可见，但相对比例可能较低 |
| 红细胞 | 多散在，形态可较完整 | 往往较多，可成堆出现，部分红细胞破碎 |
| 其他 | 可见大量脓细胞 | 可见溶组织内阿米巴滋养体，部分吞噬红细胞 |

【临床关联】上消化道出血时，红细胞常被消化液破坏，普通粪便涂片可能看不到完整红细胞，因此可借助隐血试验。

【识图】老师再次对比红细胞和白细胞：

- 红细胞：无细胞核，胞质无明显颗粒。
- 白细胞：可以见到细胞核及胞质颗粒。
- 淋巴细胞：通常可见一个较大的圆形细胞核。

### 3. 粪便吞噬细胞（Fecal Phagocytes）

可见于：

- 急性细菌性痢疾：可出现较多吞噬细胞。
- 急性出血性肠炎。
- 溃疡性结肠炎：偶见。

吞噬细胞的存在可作为炎性肠道疾病的辅助线索。

【识图】老师展示吞噬细胞胞质内含大量吞噬颗粒，细胞核被推挤至一侧的形态。

### 4. 粪便中的食物残渣（Food Residues）

#### （1）淀粉颗粒（Starch Granules）

正常粪便中一般较少。

增多见于：

- 碳水化合物消化不良。
- 腹泻、肠道转运过快。

常伴脂肪滴及肌肉纤维增多。

#### （2）脂肪（Fecal Fat）

粪便脂肪可分为三种形式：

1. 中性脂肪（Neutral Fat）
2. 游离脂肪酸（Free Fatty Acids）
3. 脂肪酸盐或结合脂肪酸（Fatty Acid Soaps）

正常粪便中可有少量脂肪成分。

老师提到脂滴多于6个/高倍镜视野可作为脂肪增加的镜检线索。

**临床意义**

- 大量中性脂肪滴：提示脂肪消化不全，需考虑胰腺外分泌功能障碍。
- 游离脂肪酸增多：可见于脂肪吸收障碍。
- 总脂肪显著增多：可见于乳糜泻（Celiac Disease）、吸收不良综合征（Malabsorption Syndrome）、急慢性胰腺炎、胰头癌和胆道梗阻等。

【识图】老师展示大小不等、圆形、折光性较强的脂肪滴。

#### （3）肌肉纤维（Muscle Fibers）

正常情况下，大量摄入肉类后可出现少量肌肉纤维。

课堂提到每张标准涂片肌肉纤维少于10个作为参考。

增多见于：

- 腹泻。
- 胃肠蠕动亢进。
- 蛋白质消化不良。
- 胰腺消化酶分泌不足等。

#### （4）结缔组织（Connective Tissue）

正常粪便中少见。

增多可见于：

- 胃蛋白酶缺乏。
- 蛋白质消化障碍。
- 腹泻。

#### （5）植物纤维及植物细胞

植物纤维（Plant Fibers）及植物细胞可随饮食摄入而出现在粪便中。

【识图】老师依次展示肌肉纤维和植物纤维的形态，帮助区分动物性和植物性食物残渣。

### 5. 粪便结晶（Fecal Crystals）

**生理性结晶**

包括少量：

- 磷酸盐结晶。
- 草酸钙结晶。
- 碳酸钙结晶。

一般临床意义不大。

**病理性结晶**

#### ① 夏科-莱登结晶（Charcot–Leyden Crystals）

【识图重点】典型呈细长的双锥形或梭形结晶，课堂图像被老师比喻为针状或梭状。

可见于：

- 阿米巴痢疾。
- 钩虫病。
- 过敏性肠炎。
- 其他嗜酸性粒细胞显著增多的肠道疾病。

其形成与嗜酸性粒细胞有关。

#### ② 血晶（Hematoidin/Hemoglobin-related Crystals）

可见于消化道出血后的粪便。

#### ③ 脂肪酸结晶（Fatty Acid Crystals）

可见于脂肪消化吸收障碍、梗阻性黄疸等情况。

### 6. 粪便中的细菌及菌群变化

正常成人肠道含大量共生微生物，主要包括：

- 大肠埃希菌（*Escherichia coli*）。
- 肠球菌（*Enterococcus*）。
- 多种厌氧菌（Anaerobic Bacteria）。

其他可见菌群：

- 产气肠杆菌。
- 变形杆菌。
- 芽孢杆菌。
- 酵母菌等。

老师介绍传统粪便涂片检查中，球菌（Cocci）与杆菌（Bacilli）比例约为1:10。

**肠道菌群失调（Intestinal Dysbiosis）**

可能发生于：

- 长期大量使用广谱抗生素。
- 使用免疫抑制剂。
- 慢性消耗性疾病等状态。

表现为菌群构成改变，课堂强调球菌与杆菌比例可能升高。

检查方法：

- 粪便涂片染色镜检可提供初步形态学线索。
- 需要确认特定细菌感染时，应结合细菌培养及病原鉴定。

【检验注意】球菌/杆菌比例是传统显微镜教学指标，不能完整代表肠道微生物组结构；现代临床不应仅凭这一比例诊断所有类型的菌群失调。

## 十三、粪便寄生虫卵检查（Stool Ova Examination）

### 1. 检查原则与常用方法

正常粪便中不应检出致病性寄生虫卵。

寄生虫感染时，可能在粪便中发现相应虫卵。

老师列举的常见虫卵包括：

- 蛔虫卵
- 鞭虫卵
- 钩虫卵
- 蛲虫卵
- 血吸虫卵
- 肺吸虫卵
- 华支睾吸虫卵
- 姜片虫卵
- 绦虫卵

课堂要求至少观察10个低倍镜视野（Low-power Fields, LPF）。

若采用每视野虫卵数的范围报告法，可记录所观察视野中的最低和最高计数，例如1～5个/低倍镜视野。

【易错】转写中先说低倍镜视野、后说高倍镜视野，应以相应检验规程规定的显微镜放大倍数为准，不能混用LPF和HPF。

常用集卵方法：

- 饱和盐水浮聚法（Saturated Salt Flotation）
- 离心沉淀法（Centrifugal Sedimentation）
- 其他沉淀集卵或浓集方法

### 2. 蛔虫卵（Ascaris lumbricoides Eggs）

蛔虫学名为似蚓蛔线虫（*Ascaris lumbricoides*）。

分为受精卵与未受精卵。

**受精蛔虫卵（Fertilized Egg）**

- 宽椭圆形。
- 棕黄色。
- 表面常有凹凸不平的蛋白质膜。
- 卵壳较厚。
- 卵内有一个较大的卵细胞。
- 卵细胞与卵壳之间可见新月形间隙。

**未受精蛔虫卵（Unfertilized Egg）**

- 长椭圆形。
- 棕黄色。
- 蛋白质膜与卵壳较厚或不规则。
- 内部充满颗粒状卵黄样物质。

**感染期虫卵**

受精卵发育后可见内部盘曲幼虫。

【识图】老师分别展示受精卵、未受精卵及含幼虫的感染期蛔虫卵，重点比较宽椭圆形和长椭圆形。

### 3. 鞭虫卵（Trichuris trichiura Eggs）

鞭虫又称毛首鞭形线虫（*Trichuris trichiura*）。

典型形态：

- 纺锤形或桶形。
- 黄褐色。
- 卵壳较厚。
- 两端各有一个透明盖塞（Polar Plug）。
- 内含一个未分裂卵细胞。

【识图重点】**两端透明盖塞**是鞭虫卵最典型的鉴别特征。

### 4. 蛲虫卵（Enterobius vermicularis Eggs）

蛲虫学名为蠕形住肠线虫（*Enterobius vermicularis*）。

- 无色透明。
- 一侧扁平，另一侧凸起。
- 侧面观察形似大写字母 **D**。
- 卵壳较薄，可见发育中的胚胎或幼虫。

【识图重点】老师反复强调蛲虫卵的“D字形”。

【临床关联】蛲虫雌虫通常在肛周产卵，**清晨肛周透明胶带法**比单次粪便检查更适合检出蛲虫卵。<Cite ref="turn675722search0"/>

### 5. 钩虫卵（Hookworm Eggs）

主要涉及十二指肠钩口线虫（*Ancylostoma duodenale*）和美洲板口线虫（*Necator americanus*）。

形态：

- 长椭圆形。
- 中等大小。
- 无色透明。
- 卵壳薄。
- 新鲜粪便内可见4～8个卵裂球。
- 卵壳与卵裂球之间有明显间隙。

【识图重点】**卵壳薄、卵内4～8个细胞、细胞与卵壳之间有间隙**。

若粪便放置时间较长，胚胎可继续分裂，甚至发育为幼虫。

【易错】两类主要人体钩虫卵形态相似，单凭虫卵形态通常不能准确鉴定到物种。<Cite ref="turn675722search2"/>

### 6. 姜片虫卵（Fasciolopsis buski Eggs）

姜片虫为布氏姜片吸虫（*Fasciolopsis buski*），是一种大型肠道吸虫。

- 为人体寄生蠕虫中体积较大的虫卵之一。
- 长椭圆形。
- 淡黄色。
- 卵壳比较薄。
- 一端有不太明显的卵盖（Operculum）。
- 卵内有一个卵细胞和大量卵黄细胞。

【识图】老师强调其体积特别大，以及不太明显的卵盖。

### 7. 肺吸虫卵（Paragonimus westermani Eggs）

肺吸虫主要指卫氏并殖吸虫（*Paragonimus westermani*）。

形态：

- 椭圆形。
- 金黄色、黄褐色。
- **卵盖较大而明显**。
- 卵壳厚薄不均。
- 内含卵细胞和卵黄细胞。

【识图重点】卵盖明显、卵壳厚薄不均。

### 8. 日本血吸虫卵（Schistosoma japonicum Eggs）

日本血吸虫（*Schistosoma japonicum*）成虫雌雄异体，雌雄常呈合抱状态。

老师介绍：

- 雌虫位于雄虫抱雌沟（Gynecophoral Canal）内。

虫卵特点：

- 椭圆形。
- 淡黄色。
- 卵壳较薄。
- **没有卵盖**。
- 一侧可有小侧棘（Lateral Spine）。
- 成熟虫卵内有毛蚴（Miracidium）。

【识图重点】日本血吸虫卵的侧棘较小，可能不十分明显。<Cite ref="turn442703search0"/>

### 9. 猪带绦虫卵（Taenia solium Eggs）

猪带绦虫又称链状带绦虫（*Taenia solium*）。

形态：

- 近圆形。
- 外层卵壳较薄。
- 胚膜（Embryophore）厚，呈棕黄色。
- **胚膜具有放射状条纹（Radial Striations）**。
- 内有六钩蚴（Hexacanth Embryo/Oncosphere），具有6个小钩。

【识图】老师重点展示放射状条纹及内部6个小钩。

【易错】猪带绦虫与牛带绦虫（*Taenia saginata*）的虫卵形态极为相似，**单凭虫卵形态通常不能可靠鉴别两者**。

### 10. 华支睾吸虫卵（Clonorchis sinensis Eggs）

华支睾吸虫（*Clonorchis sinensis*），俗称肝吸虫。

特点：

- 体积较小，形似芝麻。
- 黄褐色。
- 卵壳略厚。
- 一端有卵盖。
- 卵盖与卵壳交界处形成肩峰样突起。
- 另一端可见小疣状突起（Abopercular Knob）。
- 卵内可见成熟毛蚴。

【识图重点】**小体积、卵盖肩峰、对端小疣**是华支睾吸虫卵的典型形态特征。<Cite ref="turn442703search3"/>

### 11. 寄生虫卵综合识图复习

老师随后集中展示并比较：

- 受精蛔虫卵：宽椭圆形，外层蛋白膜明显。
- 未受精蛔虫卵：长椭圆形，内部颗粒较多。
- 钩虫卵：薄壳，卵裂球和卵壳之间有空隙。
- 蛲虫卵：一侧扁平，呈D形。
- 鞭虫卵：两端盖塞。
- 华支睾吸虫卵：体积小，卵盖及小疣明显。

## 十四、粪便中的肠道原虫（Intestinal Protozoa）

老师介绍常见肠道原虫及相关微生物，包括：

- 溶组织内阿米巴（*Entamoeba histolytica*）。
- 蓝氏贾第鞭毛虫（*Giardia duodenalis*）。
- 隐孢子虫（*Cryptosporidium*）。
- 芽囊原虫（*Blastocystis* spp.）。

### 1. 溶组织内阿米巴（Entamoeba histolytica）

主要观察两个生活史阶段：

- 滋养体（Trophozoite）
- 包囊（Cyst）

**标本检查方法**

- 新鲜粪便中的脓血黏液部分：直接湿片检查滋养体。
- 成形粪便：可用碘液染色观察包囊。
- 铁苏木素染色（Iron Hematoxylin Stain）等可用于观察原虫细胞结构。

**滋养体形态**

- 虫体形态可变，在固定染色标本中可呈圆形或卵圆形。
- 内质颗粒较细小、均匀。
- 可吞噬红细胞。
- 细胞核通常为1个。
- 核膜内侧有排列较规则的周边染色质。
- 核仁或核内体（Karyosome）一般较小且位于中央。

【识图】老师展示了胞质内被吞噬的红细胞，以及细胞核中央的核内体。

【临床关联】发现吞噬红细胞的滋养体，对溶组织内阿米巴感染具有重要提示价值。

随后老师展示溶组织内阿米巴包囊的铁苏木素染色图和碘液染色图，重点让学生对比不同染色方式下的核结构。

### 2. 蓝氏贾第鞭毛虫（Giardia duodenalis）

亦称蓝氏贾第鞭毛虫、兰伯贾第鞭毛虫，旧名包括 *Giardia lamblia*、*Giardia intestinalis*。

**易感或相关人群**

- 旅行者。
- 男男性行为人群。
- 胃酸缺乏者。
- 免疫功能低下者。
- 部分胃肠手术后的患者。

【临床关联】可引起急性或慢性腹泻、脂肪吸收不良、腹胀和营养吸收障碍。

**滋养体形态**

- 梨形（Pear-shaped）。
- 左右对称。
- 腹侧有吸盘（Ventral Adhesive Disc）。
- 有2个明显的细胞核。
- 每个核中可见核内体。
- 具有4对、共8根鞭毛。
- 可见中体（Median Bodies）及轴丝等结构。

【术语纠正】老师说“四根鞭毛”，根据规范形态应为**4对鞭毛，共8根**。<Cite ref="turn606281search2"/>

【识图重点】两个并排的细胞核非常明显，整体有时类似一张“人脸”，其中两个核像眼睛。

### 3. 隐孢子虫（Cryptosporidium）

隐孢子虫属于机会性感染相关的寄生原虫。

临床特点：

- 可引起腹泻，部分患者病程较长。
- 儿童和免疫缺陷患者易感。
- 艾滋病（AIDS）患者可能发生严重、持续性腹泻。

【临床关联】隐孢子虫是免疫抑制患者慢性腹泻的重要鉴别病因。

检查方法：

- 粪便检查及特殊染色。
- 改良抗酸染色（Modified Acid-fast Staining）可用于观察卵囊。
- 也可使用抗原检测、核酸扩增检测等方法。

【术语纠正】转写中的“茚三酚染色、碳酸染色法”不能直接作为隐孢子虫的标准检查名词，应以**改良抗酸染色**等规范名称为准。

### 4. 芽囊原虫（Blastocystis spp.）

【术语纠正】老师所说“人牙孢子虫”“人牙囊原虫”应为**芽囊原虫**，旧称人芽囊原虫（*Blastocystis hominis*）。

可存在于人类和多种动物消化道。

老师介绍，其与其他原虫包囊、白细胞及粪便杂质有时需要鉴别。

**形态特点**

- 虫体大小变化较大。
- 多呈圆形或卵圆形。
- 课堂提到直径范围约4～63 μm，多数约6～15 μm。
- 光镜下可观察到中央较大的空泡样结构。
- 细胞质呈周边薄层分布。
- 核可位于周边，数量不等。

**体外培养中可见的类型**

1. 空泡型（Vacuolar Form）
2. 颗粒型（Granular Form）
3. 阿米巴型（Amoeboid Form）
4. 复分裂相关形态（Schizont-like/Division Forms，旧形态学描述）

在粪便中最常见的是**空泡型**。

**染色方法**

老师提到瑞氏染色（Wright Stain）等染色方式，可帮助观察虫体结构。

**与白细胞的鉴别**

老师介绍一种传统水处理观察法：将生理盐水换为蒸馏水，利用不同细胞或虫体对低渗环境的耐受差异进行辅助区分。

【检验注意】低渗破坏试验不能单独作为鉴定依据，白细胞也可能受到低渗影响。规范识别还应结合湿片、固定染色、形态学及必要的分子检测。

【医学补充】芽囊原虫在有症状和无症状人群中均可检出，其致病性具有争议，并非检出就意味着一定需要治疗。<Cite ref="turn384605search0"/>

### 5. 粪便中的酵母菌（Yeast）

形态：

- 圆形或卵圆形。
- 常见出芽生殖。
- 可排列为短链状。

【识图】老师指出带有芽体的酵母菌，并与红细胞进行比较。

**酵母菌与红细胞鉴别**

| 鉴别项目 | 酵母菌 | 红细胞 |
|---|---|---|
| 正常粪便中 | 可少量存在 | 通常不应检出 |
| 形态 | 圆形或卵圆形 | 双凹圆盘形 |
| 折光性 | 较强 | 相对较弱 |
| 出芽 | 可见 | 不出现 |
| 染色 | 菌体结构可保存较完整 | 易发生形态改变或破坏 |
| 高渗环境 | 相对稳定 | 可皱缩 |
| 低渗环境 | 相对稳定 | 可膨胀、溶血 |

【识图重点】**出芽结构**是区分酵母菌和红细胞的重要特征。

### 6. 粪便中的霉菌（Mold/Fungi）

正常新鲜粪便中通常较少见明显霉菌结构。

如观察到霉菌，应先排除：

- 采集容器污染。
- 粪便在室温下暴露过久导致的环境污染。

此外，长期大量使用广谱抗生素可破坏正常菌群平衡，增加真菌过度增殖或继发感染的风险。

【临床关联】老师以抗生素使用后出现的二重感染（Superinfection）为例，说明微生态失衡与真菌异常增殖的关系。

# 十五、脑脊液检验（Cerebrospinal Fluid Analysis）

## 1. 脑脊液的形成及基本概念

**脑脊液（Cerebrospinal Fluid, CSF）**是循环于脑室、蛛网膜下腔及脊髓中央管等部位的无色透明液体。

主要由脑室脉络丛（Choroid Plexus）通过主动分泌及超滤等机制形成，脑室室管膜及其他脑脊液相关界面也参与液体交换。

**正常脑脊液总容量**

- 成人：课堂给出约120～180 mL。
- 新生儿：约10～60 mL。

### 2. 脑脊液的四项生理功能

1. **缓冲与保护（Cushioning and Protection）**：缓冲机械冲击，减少脑组织受到的损伤。
2. **物质运输（Transport）**：参与代谢产物、信号物质等运输。
3. **维持内环境（Homeostasis）**：参与调节颅内压力（Intracranial Pressure, ICP）及酸碱环境。
4. **参与神经内分泌调节（Neuroendocrine Regulation）**：与神经系统内信号物质交换有关。

## 十六、脑脊液标本采集与处理

### 1. 标本采集

脑脊液通常由临床医生通过腰椎穿刺（Lumbar Puncture, LP）采集。

课堂介绍常规分为3管，每管约2 mL：

| 标本管 | 用途 |
|---|---|
| 第一管 | 化学及免疫学检查 |
| 第二管 | 微生物学检查 |
| 第三管 | 常规检查及细胞计数 |
| 另取标本 | 怀疑恶性肿瘤时进行脱落细胞学检查（CSF Cytology） |

【检验注意】不同医院可能采用不同分管流程，但尽量避免用第一管进行细菌培养，以降低皮肤污染风险。<Cite ref="turn384605search5"/>

### 2. 标本保存与送检

老师强调：

- 脑脊液采取后应立即送检。
- 尽量在1小时内完成常规检验。
- 长时间存放可能导致细胞破坏、葡萄糖下降及病原体检出率降低。

课堂还提到“2～4℃保存”的原则，但需要区分检验用途。

【重要纠正】**用于细菌培养的脑脊液不应常规冷藏**，应迅速送检。疑似细菌性脑膜炎时，冷藏可能影响某些病原体存活。细胞学、生化项目则按各实验室的标本稳定性要求处理。<Cite refs={["turn384605search1","turn384605search5"]}/>

## 十七、脑脊液外观和理学检查

### 1. 颜色（CSF Color）

正常脑脊液为无色、透明。

| 颜色 | 主要原因 | 临床关联 |
|---|---|---|
| 无色 | 正常或部分非化脓性病变 | 正常CSF、病毒性脑膜炎、轻型结核性脑膜炎、脊髓灰质炎、神经梅毒等 |
| 红色 | 出血或穿刺损伤 | 蛛网膜下腔出血、脑室出血、创伤性穿刺 |
| 黄色 | 脑脊液黄变症（Xanthochromia） | 陈旧性出血、黄疸、脑脊液循环受阻、色素增多 |
| 乳白色 | 白细胞、脓性成分增多 | 化脓性脑膜炎 |
| 淡绿色 | 脓性成分、某些细菌色素等 | 铜绿假单胞菌等感染 |
| 褐色、黑色 | 色素增多 | 黑色素瘤累及脑膜、高胆红素血症等 |

**脑脊液黄变症（Xanthochromia）**

由于血红蛋白降解产物、胆红素或其他色素在脑脊液中积累，使脑脊液呈黄色。

【临床关联】蛛网膜下腔出血（Subarachnoid Hemorrhage, SAH）后可出现黄变症，尤其有助于部分延迟就诊患者的辅助诊断。<Cite ref="turn606281view0"/>

### 2. 透明度（CSF Clarity）

脑脊液透明度与其中细胞、细菌及蛋白等含量有关。

- 正常：清晰透明。
- 化脓性脑膜炎：明显浑浊，可呈乳白色。
- 结核性脑膜炎：轻微浑浊，可呈毛玻璃样外观。
- 穿刺损伤：混入红细胞，可呈红色浑浊。

## 十八、脑脊液细胞成分检查

### 1. 正常细胞计数

课堂提供的参考范围：

| 项目 | 成人 | 儿童 | 新生儿 |
|---|---|---|---|
| 红细胞（RBC） | 正常应无或极少 | — | — |
| 白细胞（WBC） | 0～5 × 10⁶/L | 0～7 × 10⁶/L | 0～27 × 10⁶/L |

注意：\(10^6/L\) 等于1个/μL，因此成人CSF白细胞0～5 × 10⁶/L相当于0～5个/μL。

正常CSF白细胞主要为：

- 淋巴细胞（Lymphocytes）
- 单核细胞（Monocytes）

老师提到正常淋巴细胞与单核细胞的比例约为3:1。

【识图】老师展示：

- 淋巴细胞：单一圆形核。
- 中性分叶核粒细胞：核呈明显分叶。
- 中性杆状核粒细胞：核呈杆状。

部分标本也可见腔壁细胞；穿刺损伤时可带入皮肤上皮细胞、软骨细胞、红细胞或中性粒细胞。

### 2. 脑脊液细菌学检查

正常脑脊液应无致病菌。

排除污染后若检测到病原体，应高度重视，结合培养、涂片、分子检测以及临床表现判断。

### 3. 细胞增多及分类的临床意义

| CSF改变 | 主要提示疾病 |
|---|---|
| 中性粒细胞显著增多 | 化脓性脑膜炎 |
| 红细胞显著增多 | 蛛网膜下腔出血、脑室出血或穿刺损伤 |
| 早期中性粒细胞增多，后期淋巴细胞增多 | 结核性脑膜炎 |
| 淋巴细胞、单核细胞和浆细胞同时存在 | 可见于结核性脑膜炎 |
| 嗜酸性粒细胞轻中度增多 | 寄生虫感染及其他嗜酸性脑膜炎 |
| 淋巴细胞正常或轻度增多 | 病毒性、部分真菌性脑膜炎，以及部分非感染性神经系统疾病 |

【易错】CSF细胞分类具有时间依赖性。例如病毒性脑膜炎早期也可能出现中性粒细胞占优势，不能根据一次细胞分类单独确诊病原体。

## 十九、脑脊液化学检查——潘氏试验

### 1. 潘氏试验（Pandy's Test）的原理

潘氏试验是一种传统脑脊液蛋白定性试验。

主要利用脑脊液中的球蛋白（Globulin）与苯酚（Phenol，又称石炭酸）试剂作用，形成白色浑浊或沉淀。

正常脑脊液以白蛋白为主，蛋白含量较低，潘氏试验通常为阴性。

脑膜炎等病理状态下，蛋白含量特别是球蛋白增加，可使试验呈阳性。

### 2. 试剂制备与操作

老师介绍的操作流程：

1. 取10 g苯酚，加入约200 mL热蒸馏水。
2. 混匀后，按课堂方法在37℃放置48小时，取上清液备用。
3. 取约10 mL试剂于试管中。
4. 加入1滴脑脊液。
5. 在黑色背景下观察是否出现浑浊或沉淀。

【实验操作】试剂配制中的单位以实验指导书和本实验室SOP为准，苯酚具有毒性，不能随意自行操作。

### 3. 结果判断

| 结果 | 反应表现 |
|---|---|
| 阴性（−） | 澄清，无明显浑浊 |
| 弱阳性（+） | 灰白色云雾状浑浊 |
| 阳性（++） | 白色浑浊 |
| 强阳性（+++） | 白色浓絮状沉淀 |
| 极强阳性（++++） | 白色凝块状沉淀 |

浑浊或沉淀越明显，通常提示球蛋白含量越高，但属于半定量判断。

## 二十、常见中枢神经系统疾病的脑脊液改变

【重点】老师通过表格比较不同疾病的脑脊液外观、蛋白、葡萄糖、氯化物和细胞分类。

| 疾病 | 外观 | 蛋白质 | 葡萄糖 | 氯化物 | 细胞及病原学特点 |
|---|---|---|---|---|---|
| 化脓性脑膜炎（Pyogenic Meningitis） | 明显浑浊，可有脓性凝块 | 显著↑ | 显著↓ | 可↓ | 细胞显著↑，以中性粒细胞为主，可检出致病菌 |
| 结核性脑膜炎（Tuberculous Meningitis） | 微浑、毛玻璃样，可形成纤维蛋白薄膜 | ↑ | ↓ | 常↓ | 早期中性粒细胞较多，后期淋巴细胞占优势；抗酸杆菌或结核培养可阳性 |
| 病毒性脑膜炎（Viral Meningitis） | 清晰或微浑 | 正常或轻度↑ | 通常正常 | 通常正常 | 细胞轻中度↑，常以淋巴细胞为主；常规细菌培养阴性 |
| 流行性乙型脑炎（Japanese Encephalitis） | 清晰或微浑 | 轻度↑ | 通常正常 | 通常正常 | 早期中性粒细胞可占优势，后期以淋巴细胞为主 |
| 新型隐球菌性脑膜炎（Cryptococcal Meningitis） | 清晰或微浑 | 轻中度↑ | 常↓ | 可↓ | 淋巴细胞为主，可检测隐球菌抗原等 |
| 脑室或蛛网膜下腔出血 | 红色浑浊 | ↑ | 可有变化 | 常正常 | 红细胞明显增多，部分阶段可有中性粒细胞反应 |
| 脑肿瘤（Brain Tumor） | 常清晰 | 可轻度↑ | 多正常 | 多正常 | 可见细胞轻度增多，部分患者可发现肿瘤细胞 |
| 神经梅毒（Neurosyphilis） | 多清晰 | 可轻度↑ | 多正常 | 多正常 | 可有淋巴细胞增多，需结合CSF梅毒相关检测 |

【检验注意】这张表是教学中的典型模式。临床必须结合脑脊液开放压、CSF/血糖比值、细菌培养、涂片、病原核酸检测及其他特异性检测，不能依靠某一项指标区分所有类型脑膜炎。<Cite ref="turn606281view0"/>

# 二十一、浆膜腔积液检验（Serous Effusion Analysis）

## 1. 浆膜腔及积液的基本概念

老师介绍人体常见的体腔，包括：

- 胸膜腔（Pleural Cavity）
- 腹膜腔（Peritoneal Cavity）
- 心包腔（Pericardial Cavity）
- 关节腔（Joint Cavity）

【解剖补充】严格而言，关节腔属于滑膜腔（Synovial Cavity），与胸膜腔、腹膜腔和心包腔等浆膜腔在组织结构上不同，但二者的积液都可纳入体液检验范畴。

正常情况下，浆膜腔内存在少量液体，主要起**润滑作用（Lubrication）**，减少脏器表面运动时的摩擦。

液体形成与吸收取决于：

- 毛细血管流体静压（Hydrostatic Pressure）。
- 血浆胶体渗透压（Colloid Osmotic Pressure）。
- 血管壁通透性。
- 淋巴液回流。

病理状态下，液体生成增多或吸收减少，可导致积液（Effusion）。

按部位可分为：

- 胸腔积液（Pleural Effusion）
- 腹腔积液或腹水（Ascites）
- 心包积液（Pericardial Effusion）

按性质分为：

- 漏出液（Transudate）
- 渗出液（Exudate）

【考点·本章重点】老师明确强调：**浆膜腔积液检验中，漏出液和渗出液的鉴别是重点。**

浆膜腔积液检验主要用于判断积液性质，并辅助确定形成积液的病因。

## 二十二、漏出液与渗出液的形成机制

### 1. 漏出液（Transudate）

**定义**

漏出液是由非炎症性因素引起，水分及少量溶质通过毛细血管滤出并积聚于组织间隙或体腔内所形成的液体。

主要与血管内外压力平衡改变有关，并非以炎症性血管通透性增加为主要机制。

老师依次介绍以下形成原因。

#### （1）血浆胶体渗透压降低

血浆白蛋白（Serum Albumin）具有维持血管内胶体渗透压的重要作用。

当白蛋白浓度显著下降时，血管内保留水分的能力降低，液体更容易进入组织间隙和体腔。

常见疾病：

- 肾病综合征，尿蛋白大量丢失。
- 重度营养不良。
- 晚期肝硬化。
- 重症贫血等严重全身疾病。

课堂提到，当血浆白蛋白低于约25 g/L时，发生胸腹腔积液的可能性增加。

#### （2）毛细血管流体静压升高

当静脉回流受阻或静脉压力升高时，毛细血管内液体更容易向组织间隙滤出。

常见原因：

- 静脉血栓形成。
- 静脉回流受阻。
- 肿瘤压迫静脉。
- 充血性心力衰竭（Congestive Heart Failure, CHF）。
- 晚期肝硬化及门静脉高压等。

#### （3）淋巴回流障碍

淋巴液无法正常回流，造成体腔液体积聚。

例如：

- 丝虫阻塞淋巴管。
- 肿瘤压迫淋巴管。

【易错】单纯淋巴回流障碍引起的积液不一定符合典型低蛋白漏出液的特点，尤其乳糜性积液需要单独分析。

#### （4）水钠潴留（Sodium and Water Retention）

肾脏排钠排水功能受影响，使细胞外液增加，促进积液形成。

常见于：

- 晚期肝硬化。
- 充血性心力衰竭。
- 各种伴水钠潴留的肾脏疾病。

【机制总结】

漏出液形成的核心是**液体滤出与回流平衡失调**，常与胶体渗透压下降、流体静压升高、水钠潴留等有关。

### 2. 渗出液（Exudate）

**定义**

渗出液是由于炎症、肿瘤或局部组织损伤等，使血管壁通透性增加，液体及蛋白质、细胞等成分从血管内进入组织或体腔形成的积液。

**形成机制**

在病原微生物毒素、缺氧和炎症介质（Inflammatory Mediators）作用下：

1. 血管内皮细胞受损或细胞间连接改变。
2. 血管通透性（Vascular Permeability）增高。
3. 大分子血浆蛋白可以进入积液，包括白蛋白、球蛋白和纤维蛋白原。
4. 炎症细胞迁出血管，进入积液。
5. 血管损伤较严重时，红细胞也可能进入积液。

因此，渗出液通常具有**蛋白含量较高、细胞成分较多、可能含纤维蛋白原及炎症产物**等特点。

**常见病因**

- 细菌等病原微生物感染。
- 结核感染。
- 非感染性炎症。
- 外伤及局部组织损伤。
- 血液、胆汁、胰液或胃液刺激。
- 恶性肿瘤。

【临床关联】恶性肿瘤可通过血管通透性改变、胸膜或腹膜浸润、淋巴回流障碍等机制形成积液，通常属于渗出性积液。

## 二十三、浆膜腔积液外观及理学检查

### 1. 颜色（Effusion Color）

积液可以呈淡黄色、红色、脓黄色、乳白色或绿色等。

**（1）黄色或淡黄色积液**

典型漏出液多呈淡黄色、浆液性（Serous）外观。

渗出液也可以呈黄色，但颜色可能更深、更浑浊。

【易错】原转写中有一次出现“渗出液颜色较浅、漏出液较深”的表述，与后续总结表矛盾。应以最后鉴别表所述“漏出液常为淡黄色浆液性、渗出液颜色不定”为主。

**（2）红色积液（Hemorrhagic Effusion）**

血性积液可根据颜色报告为：

- 淡红色。
- 红色。
- 暗红色。

常见原因：

- 结核相关炎症。
- 恶性肿瘤。
- 出血性疾病。
- 内脏损伤。
- 穿刺损伤。

**（3）脓黄色积液（Purulent Effusion）**

通常由于大量炎症细胞、细菌及坏死物质存在。

主要见于化脓性感染。

**（4）乳白色积液（Milky Effusion）**

主要区分：

- 真性乳糜液（Chylous Effusion）：富含乳糜微粒（Chylomicrons），可由胸导管损伤、淋巴管阻塞等引起。
- 假性乳糜液（Pseudochylous Effusion）：多与长期积液中的胆固醇等脂质积累有关。

鉴别方法包括：

- 脂蛋白分析。
- 乙醚试验等传统方法。
- 显微镜检查。
- 甘油三酯和胆固醇测定。

**（5）绿色积液**

可见于某些感染，例如铜绿假单胞菌（*Pseudomonas aeruginosa*）相关感染；其他胆汁色素等因素也可能使积液呈绿色。

### 2. 透明度（Clarity）

积液透明度一般报告为：

- 清晰（Clear）
- 微浑（Slightly Turbid）
- 浑浊（Turbid）

典型特点：

- 漏出液：通常清晰透明。
- 渗出液：因细胞、蛋白、细菌或其他成分增加，常呈不同程度的浑浊。
- 乳糜液：由于含有大量乳糜微粒，通常呈乳白色浑浊。

### 3. 凝固性（Coagulation）

**漏出液**

纤维蛋白原（Fibrinogen）含量低，通常不容易自行凝固。

**渗出液**

含较多纤维蛋白原和其他凝血相关物质，可能自行凝固或形成凝块。

【易错】渗出液并非一定凝固。

当积液中含有较多纤溶相关成分时，已经形成的纤维蛋白可能被降解，导致积液不出现明显凝块。

### 4. 比密（Specific Gravity）

可使用比重计（Hydrometer）或折射仪（Refractometer）进行测定。

比密与积液中蛋白质及其他溶质的浓度有关。

课堂参考：

- 漏出液：比密通常小于1.015。
- 渗出液：比密通常大于1.018。

这属于传统鉴别标准，实际判定还需结合蛋白、LDH及其他指标。

## 二十四、浆膜腔积液化学分析

主要检测项目包括：

- 酸碱度（pH）
- 蛋白质（Protein）
- 葡萄糖（Glucose）
- 脂类（Lipids）
- 酶类（Enzymes）
- 肿瘤标志物（Tumor Markers）

目前多数定量项目可由自动生化分析仪完成。

### 1. 黏蛋白定性试验——李凡他试验（Rivalta Test）

【实验重点】老师介绍的传统人工检测方法，用于辅助鉴别漏出液和渗出液。

**（1）原理**

李凡他试验主要检测积液中的黏蛋白（Mucin/Mucoprotein）。

黏蛋白是一类酸性糖蛋白（Acidic Glycoprotein），在稀醋酸环境中可形成白色云雾状沉淀。

老师提到黏蛋白等电点约为pH 3～5。

- 渗出液：黏蛋白含量较高，试验多呈阳性。
- 漏出液：黏蛋白含量较低，试验多呈阴性。

**（2）操作**

按照课堂描述：

1. 在量筒中加入约100 mL蒸馏水。
2. 加入2滴冰醋酸（Glacial Acetic Acid）。
3. 混匀，形成稀醋酸溶液。
4. 向溶液中缓慢滴入1～2滴待测浆膜腔积液。
5. 观察液滴在水中的扩散和沉淀情况。

**（3）结果判断**

- 阳性：形成白色云雾状沉淀，沉淀持续存在，并可能逐渐向量筒下方沉降。
- 阴性：液滴迅速散开，没有形成持续性白色沉淀。

课堂讲述中还以沉淀是否下降至50 mL刻度以下作为观察描述。

**临床意义**

李凡他试验阳性支持渗出液；阴性支持漏出液。

【易错】李凡他试验是传统辅助方法，受积液成分和方法学影响，不能单独作为现代胸腔积液分类的决定性证据。

### 2. 乳酸脱氢酶（Lactate Dehydrogenase, LDH）

【重点】LDH用于鉴别漏出液与渗出液，也可辅助评价积液中组织损伤、炎症和肿瘤相关变化。

**课堂所述参考**

- 渗出液LDH常高于200 U/L。
- 积液LDH/血清LDH比值大于0.6，可支持渗出液。

【单位纠正】转写中的“200 U/mL”应为**200 U/L**，但200 U/L也不是所有实验室通用的固定界值。

**不同渗出液中的LDH变化**

老师介绍，典型情况下：

化脓性感染积液 LDH 活性较高，其次可见于恶性肿瘤及结核相关积液，正常或非炎性积液相对较低。

不过，各病因之间存在明显重叠。

**LDH同工酶（LDH Isoenzymes）**

老师还介绍LDH₃、LDH₄和LDH₅等同工酶的变化。

部分恶性肿瘤相关积液可出现LDH同工酶谱异常，尤其LDH₅增高等情况。

【临床注意】LDH同工酶异常不能单独确诊恶性肿瘤。

### 3. 腺苷脱氨酶（Adenosine Deaminase, ADA）

【术语纠正】转写中的“腺苷酸脱氢酶”“腺苷脱氢酶”均应更正为**腺苷脱氨酶（ADA）**。

ADA与淋巴细胞、单核-巨噬细胞相关免疫活动有关。

**临床意义**

- 结核性胸膜炎（Tuberculous Pleuritis）时，胸腔积液ADA可明显升高。
- 抗结核治疗有效后，ADA水平可能下降。
- 可辅助诊断结核性积液及观察治疗反应。

【重要数值纠正】老师转写为“ADA大于400 U/L考虑结核”，这里高度可能是口述或识别错误。结核性胸腔积液临床常用的参考截点是**ADA约40 U/L**，而非400 U/L；不同研究和实验室使用的截点可能有所不同。<Cite refs={["turn127140search7","turn127140search8"]}/>

【易错】ADA升高并非结核所特有，也可能见于脓胸、淋巴瘤及部分炎症性积液。应结合结核患病概率、影像学、病原学及必要的组织学检查判断。

### 4. 溶菌酶（Lysozyme）

溶菌酶与单核-巨噬细胞等免疫细胞的活动有关。

老师介绍：

- 结核性积液中，溶菌酶可能升高。
- 积液溶菌酶超过30 mg/L，以及积液/血清溶菌酶比值大于1.0，可作为传统辅助指标。
- 与部分癌性积液相比，结核性积液溶菌酶常较高。

**临床意义**

可辅助结核性胸膜炎的诊断，并可能用于动态观察。

【易错】不能把“癌性积液溶菌酶一定不升高”理解为绝对规律。不同恶性肿瘤及伴随炎症状态可能出现重叠。

### 5. 淀粉酶（Amylase, AMY）

积液淀粉酶升高主要与胰腺疾病和食管破裂等有关。

**胰源性腹腔积液**

可见于：

- 急性或慢性胰腺炎。
- 胰腺创伤。
- 胰管损伤或胰液漏。

老师提到，胰腺相关腹腔积液中淀粉酶活性可高于血清中的淀粉酶。

**食管破裂（Esophageal Rupture）**

食管破裂时，含有唾液淀粉酶的物质可能经破裂口进入胸腔，使胸腔积液淀粉酶升高。

【临床关联】淀粉酶升高不一定来自胰腺。应结合积液部位、病史和淀粉酶同工酶来源判断。

### 6. 碱性磷酸酶（Alkaline Phosphatase, ALP）

老师介绍部分肿瘤细胞可释放碱性磷酸酶，导致积液ALP活性升高。

课堂参考：

- 某些肿瘤性积液ALP/血清ALP比值可大于1。
- 部分其他性质积液该比值小于1。

但这一比值并不是现代通用的恶性积液诊断标准。

**小肠扭转、穿孔的临床关联**

老师特别举例：

小肠扭转或穿孔可造成腹腔积液ALP升高。

- 部分患者积液ALP可达到血清ALP约2倍。
- 老师提到发病2～3小时后可能开始升高。
- 随病情发展，ALP活性可能继续增加。

【临床意义】这一指标可作为肠道损伤的辅助线索，但不能替代临床急腹症判断、影像检查及必要的外科处理。

## 二十五、漏出液与渗出液的鉴别

【考点·重点表格】老师明确强调：**前面介绍积液的理学和化学检查，核心目的就是为了区分漏出液与渗出液。**

### 1. 课堂鉴别表

| 鉴别指标 | 漏出液 Transudate | 渗出液 Exudate |
|---|---|---|
| 产生机制 | 非炎症性因素为主 | 炎症、肿瘤、理化刺激等 |
| 颜色 | 常淡黄色、浆液性 | 不定，可为血性、脓性或乳糜性 |
| 透明度 | 透明或微浑 | 常浑浊 |
| 比密 | 常小于1.015 | 常大于1.018 |
| 自凝性 | 不易自行凝固 | 可自行凝固 |
| pH | 课堂参考常大于7.3 | 课堂参考常小于7.3 |
| 李凡他试验 | 常阴性 | 常阳性 |
| 蛋白质定量 | 常小于25 g/L | 常大于30 g/L |
| 积液/血清蛋白比值 | 常小于0.5 | 常大于0.5 |
| 葡萄糖 | 常接近血糖 | 部分炎症性积液可低于3.33 mmol/L |
| LDH | 传统参考常小于200 U/L | 传统参考常大于200 U/L |
| 积液/血清LDH比值 | 常小于0.6 | 常大于0.6 |
| 细胞计数 | 较少 | 较多 |
| 细胞分类 | 淋巴细胞、间皮细胞较常见 | 中性粒细胞或淋巴细胞增多 |
| 肿瘤细胞 | 通常无 | 恶性积液中可能检出 |
| 病原菌 | 通常无 | 感染性积液中可能检出 |

**关于细胞计数：**课堂转写为漏出液小于10×10⁶/L、渗出液大于500×10⁶/L。前一数值可能存在识别错误或使用了特定教材口径，不能在未核对PPT时视为通用标准。

**关于pH及葡萄糖：**并不是所有渗出液都存在明显低pH或低葡萄糖。例如恶性肿瘤、结核、肺栓塞等渗出液的表现可能不同。

### 2. 临床上更常用的Light标准

【临床补充】对于**胸腔积液**，目前常用Light标准（Light's Criteria）进行漏出液与渗出液的鉴别。

满足以下三项中的任意一项，即支持渗出性胸腔积液：

1. 胸腔积液蛋白/血清蛋白比值大于0.5。
2. 胸腔积液LDH/血清LDH比值大于0.6。
3. 胸腔积液LDH大于血清LDH参考区间上限的2/3。

这些标准在英国胸科学会及其他胸腔积液诊疗指南中均有使用。<Cite refs={["turn127140search1","turn127140search6"]}/>

### 3. 检验结果处于漏出液与渗出液之间的原因

老师列举了四种可能：

1. **漏出液继发感染**：原来是非炎症性积液，随后发生感染，蛋白及细胞成分升高。
2. **长期积液或反复穿刺、药物刺激**：导致积液成分发生改变。
3. **漏出液中混入较多血液**：使细胞及蛋白含量升高。
4. **浆膜原发性肿瘤**：可改变积液的形成机制和理化特点。

【临床关联】漏出液与渗出液并非永远是完全互斥、没有过渡的理化状态。不同病因可以同时存在，部分患者还会受到治疗和标本采集条件的影响。

## 二十六、临床病例：胸腔积液性质分析

【临床病例】老师最后用一个病例讲解如何综合判断积液性质。

### 1. 病例资料

**患者：**江某，男性，50岁，职业为外科医生。

**主诉：**咳嗽、胸闷、气促1天，急诊入院。

**体格检查：**

- 胸部局部叩诊呈浊音（Dullness to Percussion）。
- 呼吸音减低（Decreased Breath Sounds）。

上述表现提示胸腔内可能存在积液。

### 2. 胸腔积液实验室检查

| 检查项目 | 结果 | 分析 |
|---|---|---|
| 外观 | 红色、浑浊 | 血性积液表现 |
| 凝固性 | 易凝固 | 支持渗出液 |
| 蛋白质 | 53.1 g/L | 明显超过课堂渗出液参考30 g/L |
| 李凡他试验 | 阳性 | 支持渗出液 |
| 葡萄糖 | 17.9 mmol/L | 明显升高，需结合血糖及代谢状态判断 |
| LDH | 577 U/L | 支持渗出液及组织损伤活动 |
| C反应蛋白（CRP） | 升高 | 提示炎症反应 |
| 肿瘤标志物 | 课堂提到CA相关指标、AFP和CA125升高 | 提供肿瘤相关诊断线索，但特异性有限 |
| 细胞计数 | 超过500×10⁶/L | 细胞成分较多，支持渗出液 |

### 3. 初步判断

【课堂结论】根据积液外观、易凝固、蛋白质53.1 g/L、李凡他试验阳性、LDH 577 U/L及细胞计数增加，老师判断其属于**渗出性胸腔积液（Exudative Pleural Effusion）**。

【易错】虽然课堂比较表中提到部分渗出液葡萄糖下降，但本例葡萄糖为17.9 mmol/L，说明**不能凭葡萄糖是否降低来决定积液是否为渗出液**。

同时，肿瘤标志物升高不等于已经证实恶性肿瘤。

### 4. 细胞学进一步检查

老师随后介绍，将积液离心：

1. 收集沉渣。
2. 制备涂片。
3. 进行染色。
4. 显微镜下观察细胞形态。

【识图】老师展示染色后的细胞学图片，指出左侧可见**细胞呈团块状聚集（Cell Clusters）**。

这种聚集方式需要进一步观察细胞核大小、核质比、染色质、核仁、细胞排列及异型性等特征，以判断是否存在异常细胞或恶性细胞。

**录音至此结束。** 转写文本停在老师描述镜检图像的过程中，未继续给出完整的细胞学诊断、病理结果或最终病因，因此不能将该病例直接确定为恶性胸腔积液。
